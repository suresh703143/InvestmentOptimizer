Dynamic Programming - Knapsack Optimization

The Dynamic Programming approach solves the constrained optimization problem by building a table of optimal subproblems. It ensures the global optimum is found by considering all possible combinations within constraints.

✓ Guaranteed optimal solution
✓ Time Complexity: O(n × W)
✓ Space Complexity: O(n × W)

Greedy Algorithm - Fast Approximation

The Greedy approach selects assets with the best return-to-risk ratio sequentially. While faster than DP, it may not guarantee the global optimum but provides good approximations with minimal computation.

⚡ Faster execution time
⚡ Time Complexity: O(n log n)
⚠️ May not find global optimum
